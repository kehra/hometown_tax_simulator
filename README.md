# 個人事業主向け ふるさと納税シミュレータ

個人事業主・フリーランス専用のふるさと納税寄附上限額シミュレーターです。  
売上・経費・青色申告特別控除や各種所得控除から、実質自己負担2,000円で寄附できる上限目安額を正確に試算します。

最大の特徴は、**「計算式のウラ側」をステップ順（事業所得 → 各種控除 → 課税所得 → 住民税所得割額 → 法定限度額算定式）に実数値を代入した形で完全可視化**することです。

---

## ✨ 主な機能と特徴

### 1. 2つの入力モード
- **かんたんモード**:
  - 確定申告書Bの「課税される所得金額（㉖番）」を1つ入力するだけの一発試算
  - または「年間売上・年間経費」と家族構成プリセットによるクイック試算
- **詳細モード**:
  - 確定申告書Bの項目に完全準拠
  - 青色申告特別控除（65万 / 55万 / 10万 / 白色0円）
  - 専従者給与
  - 社会保険料（国保・国民年金）、小規模企業共済等掛金（iDeCo等）
  - 配偶者（特別）控除、扶養控除（特定扶養19〜22歳、老人扶養等）
  - ひとり親・寡婦控除、障害者控除
  - 生命保険料控除、地震保険料控除、医療費控除
  - 住宅借入金等特別控除（住宅ローン控除の住民税所得割額への波及控除）

### 2. 計算式のウラ側（計算ステップ完全可視化）
- **Step 1: 事業所得の算出**（売上 − 経費 − 青色申告特別控除 − 専従者給与）
- **Step 2: 所得控除合計の算出**（基礎控除 48万円/43万円 ＋ 各種控除）
- **Step 3: 課税所得と基準税額の算出**（所得税課税所得・住民税課税所得、所得税率・控除額）
- **Step 4: 住民税所得割額の算出**（標準税率10% − 人的控除差調整控除 − 住宅ローン控除）
- **Step 5: ふるさと納税限度額の計算**（法定特例控除式への数値代入展開）

### 3. 安心・便利なブラウザキャッシュ＆操作性
- **入力内容の自動保存 & 明示的保存**: 入力値はブラウザ（`localStorage`）に安全に保持されるため、再訪時も前回の入力状態から再開できます。
- **ワンクリッククリア**: 保存キャッシュを含めた初期化が可能。
- **ワンクリック結果コピー**: 試算結果の内訳をテキスト形式でクリップボードへコピー可能。
- **完全クライアントサイド実行**: 入力データや計算処理はすべてブラウザ内で完結し、外部サーバーへの通信は一切行いません。プライバシーも安全です。

## 📖 税制計算の前提について

- **適用税法**: 現行の所得税法および地方税法、総務省のふるさと納税制度に準拠。
- **基礎控除**: 所得税 48万円、住民税 43万円（合計所得金額2,400万円以下）。
- **住民税所得割額**: 標準税率10%（道府県民税4% ＋ 市町村民税6%）。
- **特例控除額の計算式**:
  $$\text{特例控除上限} = \frac{\text{住民税所得割額} \times 20\%}{90\% - (\text{所得税率} \times 1.021)} + 2,000\text{円}$$
  ※ 復興特別所得税（102.1%）および自己負担2,000円を加味しています。
